# Portfolio presentation guide

## Workflow screenshots

Use one full workflow screenshot and two close-ups. Add short annotations for input, decision, external API, persistence, and output.

## Naming

Use action-based node names such as `Validate Telegram User`, `Get Marzban Token`, `Create VPN Account`, and `Save Access Key`.

## Case study order

1. Business problem
2. Architecture diagram
3. User journey
4. Integrations
5. Reliability and error handling
6. Result and limitations

## Visual direction

Use a white background, one accent color, generous spacing, and consistent diagram labels. Avoid screenshots that expose credentials, private IDs, or noisy unfinished branches.
