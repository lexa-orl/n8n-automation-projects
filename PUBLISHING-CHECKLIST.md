# GitHub publishing checklist

Before publishing:

- [ ] Review every JSON export for credentials, tokens, private URLs, email addresses, and table IDs.
- [ ] Replace service credentials with your own test credentials.
- [ ] Replace real customer or user data with mock data.
- [ ] Add screenshots to each project folder.
- [ ] Add a short demo video or GIF for the two strongest projects.
- [ ] Test each sanitized workflow with development data.
- [ ] Confirm that no `.env`, SQLite database, or private backup files are included.
- [ ] Add the GitHub repository URL to your CV and LinkedIn.

Recommended repository description:

> Selected n8n automation projects: Telegram bots, API integrations, AI pipelines, and operational data workflows.
