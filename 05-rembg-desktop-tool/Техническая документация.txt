Техническая документация проекта RemBG (ComfyUI/InSPyReNet GUI)

Запуск из папки 1602 команда runenv\Scripts\python.exe third_party\ComfyUI-Inspyrenet-Rembg\gui_frontend.py

1. Введение
-------------
Это локальное приложение удаляет фон с изображений, сохраняя готовое RGBA-изображение + маску. В проекте два фронтенда:
- CLI (`test_run.py`) — настраиваемая обработка через терминал.
- GUI (`gui_frontend.py`) — окно Tkinter с пресетами, логом и инструкцией.
Собранный exe (`dist/InspyrenetRembg.exe`) использует тот же GUI и запускается без Python. Документация охватывает эталонную архитектуру, назначение каждого файла и процесс сборки/рассылки.

3. Файлы верхнего уровня
--------------------------
- `check_onnx.py`: проверяет, доступна ли библиотека `onnxruntime` и какие провайдеры (CPU/GPU) установлены; служит диагностическим тестом при установке (выводит версию, провайдеры и путь к PYTHON). Используй перед сборкой на новой машине.
- `gui_annotator.py`: лёгкий Tkinter-редактор для ручного создания аннотаций (FG/BG scribbles). Работает на одном изображении: показывается оригинал, результат, маска; есть кисть, которая сохраняет поправки в `annotations/`. Инструмент помогает подготовить сложные кадры для trimap в `remove_bg_v3`.
- `make_test_image.py`: простая утилита, создаёт тестовую PNG (напоминает градиент + объекты) для проверки pipeline или GUI. Используется для демонстрации.
- `README.md`: оглавление версий `remove_bg`, пошаговая инструкция по запуску pip/venv, описание annotate-варианта. Полезно новичку, чтобы понять, зачем нужны `remove_bg_v1..v3` и как запускать.
- `remove_bg.py`, `remove_bg_v2.py`, `remove_bg_v3.py`: эволюция скриптов на базе `rembg`.
  1. `remove_bg.py` — исходная версия: обрабатывает папку, сохраняет выход `<folder>_ready`, использует `rembg.remove`, tqdm для прогресса. Поддерживает `is_image_file`, не дорабатывает альфу.
  2. `remove_bg_v2.py` — добавляет `refine_alpha_with_enclosed_bg`: использует `numpy` и `scipy.ndimage` для локального подавления шумов, сохраняет результаты в битое дерево. Включает простую альфа-рефайнмент и обновлённый CLI (параметры `--resize`, `--enforce`, etc).
  3. `remove_bg_v3.py` — фокусна на качестве: создает адаптивную trimap, сохраняет её в `annotations/`, поддерживает `cli` с `--radius`, `--steps`, `--gpu`, etc; интегрируется с графическим аннотером и готовит данные для маттинга.
- `gui_frontend.py`: основной GUI (описан дальше). Этот файл вместе с `test_run` — ядро проекта.
- `InspyrenetRembg.spec`: PyInstaller-спецификация для сборки exe; включает `icon.bmp`, `test_run.py`, `transparent_background` (через `--collect-all`), обеспечивает `--onefile` + `--noconsole`.
- `requirements.txt`: перечисляет зависимости, включая `transparent-background`, `torch`, `opencv`, `rembg`, `tkinter` и др. Установи через `pip install -r requirements.txt` после создания venv.
- `icon.bmp`: иконка для exe/ярлыка; попадает в `dist` при сборке и используется ярлыком на рабочем столе.
- `Техническая документация.txt`: текущий документ: детально описывает проект, режимы, CLI/GUI, сборку, а также множество файлов подпроектов.

4. Подкаталог `third_party/ComfyUI-Inspyrenet-Rembg`
-----------------------------------------------------
Содержит основной пакет (который мы интегрировали):
- `test_run.py`: CLI для обработки папок (см. предыдущий раздел). Этот файл является «интерфейсом» к `transparent_background`.
- `gui_frontend.py`: Tkinter GUI, который вызывает `test_run.process_files` через `importlib`; добавлены пресеты `base-super`/`auto`, кнопка “Автомат”, подробная инструкция, шейп + чистка, лог.
- `Inspyrenet_Rembg.py`, `Inspyrenet...json`, `pyproject.toml`: метаданные, лицензия MIT. `pyproject.toml` требует `transparent-background` и регистрирует ноду для ComfyUI (для интеграции в ComfyUI Manager).
- `requirements.txt`: содержит одну строку `transparent-background` — для того чтобы подключить зависимости независимо от корневого `requirements`.
- `README.md`: описание модуля, скриншоты (ссылки), инструкция по установке через ComfyUI Manager или `git clone`.
- `test_output/`: папка по умолчанию, куда `test_run.py` сохраняет результаты. Логично очищать или переносить после обработки.

5. Директории окружений и сборки
---------------------------------
- `runenv/` — основная виртуалка für запуск `third_party/...` и сборку PyInstaller: содержит `Scripts\python.exe`, `Lib\site-packages` со `transparent_background`, `torch`, `rembg`, `numpy`, `opencv-python`, `pyinstaller` и др. Поддерживает `pip`/`python` для обеспечения зависимостей.
- `venv/` — вторая копия (вероятно прежняя) venv, с собственным site-packages. Можно удалить если не используется.
- `dist/` — результат PyInstaller (`InspyrenetRembg.exe`). Распространяется вместе с `icon.bmp`, ярлык на desktop настроен через `win32com`.
- `output/` и `third_party/ComfyUI-Inspyrenet-Rembg/test_output` — каталоги с примерами результатов; можно посмотреть, как выглядят `*_rgba.png` и `_mask.png`.

6. Процесс сборки exe и ярлыка
-------------------------------
1. Устанавливаешь зависимости в `runenv`: `python -m pip install -r requirements.txt`, `pyinstaller`.
2. Собираешь командой `runenv\Scripts\python.exe -m PyInstaller --onefile --noconsole --icon icon.bmp --add-data "third_party/ComfyUI-Inspyrenet-Rembg/test_run.py;." --add-data "icon.bmp;." --collect-all transparent_background --name InspyrenetRembg third_party\ComfyUI-Inspyrenet-Rembg\gui_frontend.py`.
3. В `dist` появляется `InspyrenetRembg.exe`. Скопируй + icon в `C:\Users\User\Desktop\InspyrenetRembg`, создай ярлык (мы делали через win32com), чтобы запускать exe двойным щелчком.
4. Ярлык или exe можно пересылать: exe включает все зависимости и встроен PyTorch/transparent_background.

7. Режимы обработки: сравнительный обзор
-------------------------------------
- `base`: проверенный режим `Remover` (лучшее качество, но медленнее).
- `fast`: уменьшенное разрешение (быстрее, чуть хуже детали).
- `base-nightly`: экспериментальная версия моделей (возможно, свежие веса, но менее стабильна).
- `base-super`: `base-nightly` плюс `autocontrast`, `post_clean`, `sharpen`; после последних правок он больше не размывает, но делает картинки резкими через UnsharpMask, также уважает твой выбор `mask_morph`.
- `auto`: пресет с фиксированными значениями (max=0, threshold пуст, pre/mask blur=0, mask morph=close, clean strength=1, recursive=True, save_mask=False). Кнопка «Автомат» в GUI переключает режим и блокирует поля, CLI запускается командой `--mode auto`.

8. Пользовательские сценарии
-----------------------------
1. **CLI/Tutorial** — `runenv\Scripts\python.exe third_party\ComfyUI-Inspyrenet-Rembg\test_run.py --mode base-super --max 0 --autocontrast --mask-morph close --mask-blur 0 --post-clean --clean-strength 0.15 --sharpen-percent 150`.
2. **Автоматический режим** — нажми «Автомат» → окно заблокирует параметры → жми «Запустить» → получишь стабильный результат без размытия.
3. **Ручные эксперименты** — оставь `mode=base-nightly`, включи `mask_blur=0.5`, `clean_strength=0.2`, поиграй с `threshold`. Режимы `base-super`/`auto` доступны для пресетов.
4. **Раннее ПО (remove_bg*)** — можно использовать `remove_bg_v3.py` с `rembg` и `trimap`/`annotations` для подготовки сложных кадов, нужен `gui_annotator.py` для рисования scribbles.

9. Взаимодействие модулей
--------------------------
1. `gui_frontend` получает параметры, вызывает `process_files` через инжекцию. Внутренний поток `threading.Thread(target=_worker, kwargs=params)` не блокирует интерфейс, лог обновляется через `.after`.
2. `test_run.py` выступает как ядро: `process_files` делает все шаги обработки, `find_images` ищет файлы, `_preprocess_image`, `_postprocess_mask`, `_clean_edges` управляют спецэффектами, `UnsharpMask` возвращает чёткость. Опциональные обработчики подключаются через CLI/GUI.
3. `runenv\Lib\site-packages\transparent_background` — зависимость (Remover, InSPyReNet) скачивается автоматически. При запуске `process_files` модель загружается и кешируется.
